# Component examples

The interactive demo is started from the repository root with `npm run dev`.

- `LoadingDemo.jsx` is the original loading-screen demo with seven visual layouts and shared progress controls.
- The main demo shell in `src/App.jsx` provides tabs for Login, Sign up, Forgot password, Reset password, Verify email, Loading pages, and Error page.

The authentication forms run in demo mode until callback props are connected to your application's authentication and navigation services.
